KEY IMPLEMENTATION DETAILS
═══════════════════════════════════════════════════════════════════════════════

JWT Token Payload:
  {
    "sub": "1",                          // User ID
    "email": "demo@gmail.com",
    "role": "CUSTOMER",
    "iat": 1704067200,                   // Issued at
    "exp": 1704153600                    // Expires at (24 hours later)
  }

Secure Request Flow:
  Frontend (http://localhost:5173)
       ↓
  POST /api/auth/login
       ↓
  Backend validates & generates JWT
       ↓
  Returns: {token, userId, fullName, ...}
       ↓
  Frontend stores JWT in localStorage
       ↓
  Frontend makes request with Authorization: Bearer {JWT}
       ↓
  JwtAuthenticationFilter validates JWT
       ↓
  Spring Security context set with user info
       ↓
  Request proceeds with user context
       ↓
  Response sent to frontend

Logout Flow:
  User clicks Logout
       ↓
  Frontend calls clearToken()
       ↓
  JWT removed from localStorage
       ↓
  Page reloads
       ↓
  User logged out, redirected to login
